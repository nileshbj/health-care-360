# Health & Care 360° — Orange & Grey website package

## Pages
- `index.html` — Sample 1 (default landing page)
- `sample2.html` — Sample 2 (alternative homepage layout)
- `health-insurance.html` — Health insurance information page
- `life-insurance.html` — Dedicated life and term insurance page
- `corporate-solutions.html` — Dedicated business and corporate insurance page
- `ohc.html` — OHC & Health Camps page for Nashik

## Upload to GitHub / Netlify
Upload the complete contents of this folder to the root of your existing GitHub repository. Keep the `assets/` folder and all CSS files at the same level as the HTML files. Commit the changes; Netlify should automatically deploy. No build command is required.

The pages use Arya for display headings and Noto Sans / Noto Sans Devanagari for reading text, loaded from Google Fonts CDN with system fallbacks.

## Notes
The website is informational. Insurance availability, eligibility, premiums, benefits, exclusions and claims are subject to insurer terms and policy wording. Any solicitation or distribution must be handled by appropriately authorised persons/entities.


## Shared navigation consistency update
All six pages now use the same navigation structure and responsive mobile menu. Keep `hc360-common-nav.css` and `hc360-common-nav.js` at the repository root with the HTML files.
