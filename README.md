# Health & Care 360° — Orange & Grey redesign

## Pages
- `index.html` — Sample 1 (default landing page)
- `sample2.html` — Sample 2 (alternative homepage layout)
- `health-insurance.html` — dedicated health insurance information page
- `ohc.html` — dedicated OHC & Health Camps page for Nashik

## Design system
- Warm orange accent, charcoal typography, soft grey section backgrounds and white content cards.
- Arya for display headings; Noto Sans / Noto Sans Devanagari for paragraph and interface readability.
- Responsive mobile layout, improved section hierarchy, hover states and reduced-motion support.
- Shared `brand-refresh.css` keeps the two homepages and subpages visually consistent.

## Deploy to Netlify via GitHub
Upload the full contents of this folder to the root of the existing GitHub repository. Keep `assets/` and all CSS files at the same level as the HTML files. Commit the changes; Netlify should automatically deploy.

No build command is required. Google Fonts is loaded from the Google Fonts CDN; system fallbacks remain available if the CDN cannot load.

## Notes
The site is informational. Insurance availability, eligibility, premiums, benefits, exclusions and claims are subject to insurer terms and policy wording. Any insurance solicitation or distribution must be handled by appropriately authorised persons/entities. OHC and health camp services depend on confirmed local provider arrangements and applicable requirements.
